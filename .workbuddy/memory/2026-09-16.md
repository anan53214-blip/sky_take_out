## 套餐分类下拉框只显示 2 个的排查
- 现象：套餐管理页"套餐分类"下拉只有 人气套餐 / 商务套餐，用户以为漏写了查询接口。
- 结论：**不是 bug**。category 表靠 `type` 区分：1=菜品分类，2=套餐分类。前端按页面传参：菜品管理页 `type=1`，套餐管理页 `type=2`。服务端 `CategoryController.list(Integer type)` 无默认值，不传则返回全部 status=1 的分类。
- 后端链路：`/admin/category/list?type=2` → CategoryController.list → CategoryServiceImpl.list → CategoryMapper.xml `<select id="list">`（`where status=1 and type=#{type}`，写死了 status=1，禁用分类不会出现在下拉框）。
- 本库 category 实际数据：type=2 仅 id=13 人气套餐、id=15 商务套餐；其余 8 条为 type=1。
- 排查方法：直接 `select id,type,name,sort,status from sky_take_out.category;` 或用浏览器 Network 看请求 Query 参数。
